🚀 五分钟上手

装好、唤起、跑通第一条命令。整份手册其余的部分都是可选的。

  1. 安装。到 Releases 页下载最新版：macOS 把 .dmg 里的 Fulcrum 拖进「应用程序」；Windows 双击 .msi 安装；Linux 用 .deb / .rpm / .AppImage。没有账号，没有引导问卷。
  2. 唤起。按 Alt+Space（macOS 是 ⌥+Space），浮动面板出现在屏幕中央。再按一次，面板隐藏。热键被别的软件占了？Fulcrum 自动退到 Ctrl+Alt+Space 并提示。
  3. 跑第一条命令。输入 calc 回车——计算器打开。再唤起，输入 128*768——答案就在列表里，回车即复制。存第一个片段：输入 add snippet addr 南京西路 42 号。
  4. 粘贴回前台。在任意应用里复制一段文字。唤起面板，输入 clip 或那段文字里的任意词，回车——文字直接粘进你刚才在用的应用，不用切窗口。macOS 第一次会请求辅助功能权限，授权一次全局生效（详见 FAQ）。

截图为真实的 macOS 版本。Windows 与 Linux 面板布局相同，控件随平台风格。

整个产品就是：一个键 → 输入 → 回车。下面全是细节。

🔍 搜索一切

面板只有一个输入框，但什么都接：应用、算式、文件、网页、表情。

启动应用

输入应用名的任意片段——ffx 能找到 Firefox，手滑打错也能容忍。常用的应用会越用越靠前。

行内计算

直接敲算式：128*768、(2+3)^4、sqrt(2)、sin(pi/4)。答案出现在结果最上面，回车复制。

快捷链接

建立自己的 URL 模板：add link yt https://youtube.com/search?q={query}。之后 yt lofi 就打开 YouTube 搜索，{query} 被替换成关键词后面的内容。输入 quicklinks 查看和删除。

找文件与表情

find 发票 通过 Spotlight 搜文件名（macOS）。输入表情英文名的两个以上字母——grin、fire、heart——匹配的表情内联出现，回车直接粘贴。

📋 剪贴板历史

你复制的每段文字都会被记住——在本机、可搜索、可固定。

  • 粘贴。输入 clip 或历史内容里的任意词，回车——粘贴进你刚才在用的应用。
  • 复制而非粘贴。选中某条历史，按 ⌘K / Ctrl+K，从附加动作里选复制。
  • 开关与容量。settings → clipboard-enabled 总开关；clipboard-limit 控制保留条数。
  • 剪贴板历史保存在本地 JSON 文件，仅记录文本。插件、AI 命令或用户配置的同步可涉及对外发送，请在使用前审查数据范围。

🤖 AI（自带密钥）

AI 使用你自己的服务商。密钥保存在本地文件中，用于向所选端点鉴权；请求发送选定提示和上下文，会话历史可在本地持久化。不要把密钥、剪贴板或日志公开分享。

一次性设置（最常见的卡点）

  1. 选服务商。唤起面板，输入 settings，回车运行 ai-provider 那行，切到 OpenAI / Anthropic / Ollama。
  2. 填密钥。再次唤起面板，输入 ai key 加你的真实密钥（例如 ai key sk-…），回车。密钥落在本地，界面不会回显。
  3. Ollama 用户免密钥。只要 ollama serve 在本机跑着，选好 provider 直接用。
  4. 验证。输入 ai 你好——答案流式打进面板，即配置成功。
⚠️ 提示「没有密钥」？
先选服务商（第 1 步），再填密钥（第 2 步）——顺序反了会报「没有密钥」。换服务商后需重新填一次对应的密钥。

🪟 窗口与系统命令

输入 window 或命令名的一部分：左半屏、右半屏、最大化、近最大化、居中、还原——作用于你召唤 Fulcrum 之前最前面的那个窗口。三平台都是原生实现。

lock、sleep、restart、toggle dark mode、empty trash——Fulcrum 只列出你的平台上真实存在的命令，不会给一个点了没反应的假条目。

自定义热键

settings → hotkey 在四个预设间循环：alt+space → ctrl+alt+space → ctrl+shift+space → alt+shift+space。想用别的组合：编辑数据目录下的 settings.json，写 "hotkey": "ctrl+shift+space" 这样的值——修饰键 alt/ctrl/shift/cmd/win/super 至少一个，键位 space、a–z、0–9、f1–f12、comma、period、minus、equal、tab。三平台通用。组合被占用时 Fulcrum 自动退避并提示，菜单栏（macOS）或托盘（Windows）里也永远有 Open Fulcrum。

❓ 常见问题

数据存在哪？

全部数据在一个目录里。删掉它就是全新状态：

  • macOS：~/Library/Application Support/Fulcrum
  • Windows：%APPDATA%\Fulcrum
  • Linux：~/.local/share/fulcrum

同步 beta：把 sync-root 设到 iCloud Drive、Dropbox、Syncthing 或任何同步目录，设置与片段自动镜像过去；新机器首次启动自动恢复。剪贴板历史和 AI 密钥刻意不同步。

macOS 授权了才能用的功能

两个功能需要辅助功能权限：粘贴回前台和片段自动展开。搜索、计算、启动应用、AI 都不需要。授权路径：系统设置 → 隐私与安全性 → 辅助功能 → 打开 Fulcrum。若已打开仍不生效：先关掉再打开（重授一次）；macOS 大版本升级后偶发需要重授。首次使用时弹出的系统授权框点了「稍后」也没关系，随时可以来这里补。

Linux：X11 一切开箱即用；Wayland 装好 wtype 才能粘贴回前台，片段展开在 Wayland 上不可用。Windows：无需额外授权。

要注册账号吗？收费吗？

已有启动、剪贴板、插件、BYOK 与自有文件夹同步保持免费，无需商业账号。新工作流 Pro 尚未开售；外部模型用量另计。

支持哪些系统？各平台有差异吗？

macOS 14+（Apple silicon 与 Intel）、Windows 10（19041+）/ 11、Linux（GTK4；.deb / .rpm / .AppImage / tar.gz）。诚实清单：文件搜索仅限 macOS；片段自动展开不支持 Linux；剪贴板只收文本。其余功能三平台一致、键位一致。

同一块面板，深色主题。本站右上角 ◐ 也可以切换网站深浅色。

更新失败怎么办？

面板里输入 update → Check for updates now。更新包后台下载，macOS 原地换装重启。更新包带 Ed25519 签名——校验失败直接拒收，绝不安装损坏的包。多次失败：到 Releases 页手动下载最新版覆盖安装，设置与数据不受影响。

怎么卸载？

先退出：菜单栏（macOS）或托盘（Windows）图标 → Quit Fulcrum——这是唯一的退出方式，Esc 只是隐藏。再删应用：macOS 从「应用程序」拖进废纸篓；Windows 在「设置 → 应用」里卸载；Linux 用包管理器卸载或直接删 AppImage。想彻底清空：删掉上文的数据目录即可，辅助功能授权随应用删除自动失效。
