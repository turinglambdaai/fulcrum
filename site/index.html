Keyboard-first launcher · macOS · Windows · Linux

One keystroke. Everything within reach.

Fulcrum is a keyboard-first launcher for macOS, Windows and Linux. Press one global hotkey and a floating command palette appears: fuzzy-search apps and files, revisit your clipboard history, expand snippets, calculate, fire web-search bangs and run plugins — all on-device.

Why Fulcrum

Everything you reach for, one keystroke away.

Fulcrum stays out of the way until one hotkey calls it — then apps, files, clips, calculations and commands are a few letters away.

Blazing fuzzy search

Type a few letters and results appear as you type — sub-second fuzzy matching across apps, files and actions.

All your apps

Every installed application, one query away. Launch it, switch to it, done — no digging through menus or docks.

Clipboard history

Everything you copy is kept and searchable on-device. Paste last week's link like it was yesterday's.

Snippets

Save the replies, templates and code fragments you keep retyping — expand them anywhere by name.

Calculator with functions & constants

Inline math as you type — sqrt, sin, log and constants like π and e, without switching apps.

Web-search bangs

!g Google, !gh GitHub, !w Wikipedia, !so Stack Overflow — a bang jumps straight into the right search box.

System commands

Lock the screen, sleep, mute — system actions live in the same palette, no menu digging required.

Plugin ecosystem

A language-agnostic plugin protocol: JSON over stdio. Write plugins in any language; Fulcrum runs them.

100% on-device, private by default

Search indexes, clipboard history and snippets never leave your machine. The core needs no account.

Platforms

One Racket backend. Three first-party UIs.

Built with the Rivet framework: one shared Racket backend embedded in each app, first-party native UI on every platform. No WebView anywhere.
